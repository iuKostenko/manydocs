# IraDocs — веб-версія

Single-file web app, що генерує .docx договори з Excel-реєстру і Word-шаблона.
Все рахується **прямо в браузері** — файли нікуди не передаються. Можна
запускати з телефону, з робочого ПК, з чужого ноутбука — будь-де, де є браузер.

Демо: `https://<твій-username>.github.io/<repo>/`

## Як це працює

Користувач заходить на сторінку, перетягує два файли (`Реєстр_договорів.xlsx`
+ `Шаблон_договору_з_мітками.docx`), натискає **Згенерувати договори**.
JavaScript у браузері:

- читає xlsx через SheetJS,
- знаходить аркуші Договори / Виконавець / Замовник,
- для рядків зі статусом `Готовий до формування` лукапить сторони, рендерить
  шаблон через docxtemplater,
- пакує всі .docx + оновлену копію реєстру (статуси → `Сформовано`) у zip,
- віддає на завантаження.

Мітки в шаблоні — стандартні `{{NUM}}`, `{{VYK_NAZVA_KOROT}}`, `{{ZAM_EDRPOU}}`
тощо. Той самий набір, що й у Python/Apps Script/VBA-версіях.

## Розгортання на GitHub Pages (3 хвилини)

1. На github.com → **New repository**. Назва — будь-яка
   (наприклад `contract-generator`). Public.
2. На сторінці нового репозиторію натискаєш **uploading an existing file**.
3. Перетягуєш у вікно `index.html` і цей `README.md` (з папки `web/`). **Commit**.
4. У репозиторії → **Settings → Pages**.
5. У секції *Source* обери **Deploy from a branch** → branch `main`, folder `/ (root)`.
   **Save**.
6. Зачекай 30-60 секунд. Зверху з'явиться зелена плашка з посиланням типу
   `https://username.github.io/contract-generator/`. Заходиш — працює.

Якщо потім зміниш `index.html` і знову закоммітиш — Pages автоматично оновить
сайт через хвилину.

## Альтернативи GitHub Pages

Якщо хочеш custom-домен або swap між версіями — той самий `index.html`
працює на:

- **Cloudflare Pages** — drag-and-drop у `pages.cloudflare.com`, той самий
  HTML, безкоштовно, з власним доменом і HTTPS.
- **Netlify Drop** — `app.netlify.com/drop`, перетягнути папку, отримати URL
  за 10 секунд (без реєстрації для тестів).
- **Vercel** — `vercel.com/new`, ту ж саму папку, GitHub-інтеграція з
  auto-deploy.

Усі три безкоштовні для приватних проектів цього обсягу.

## Приватність

Жодного бекенду. Усі обчислення — JavaScript у твоїй вкладці браузера.
Реєстр з ЄДРПОУ і реквізитами не залишає твою машину. Завантажений зі сторінки
.zip — це той самий .zip, що згенеровано локально твоїм же браузером.

Зовнішні залежності (CDN-скрипти) — це лише сама бібліотечна логіка:
- [SheetJS](https://sheetjs.com/) — читання .xlsx
- [docxtemplater](https://docxtemplater.com/) + [PizZip](https://github.com/Stuk/jszip) — рендеринг .docx
- [JSZip](https://stuk.github.io/jszip/) + [FileSaver.js](https://github.com/eligrey/FileSaver.js/) — пакування і завантаження
- [Tailwind CSS](https://tailwindcss.com/) — стилі

CDN віддає їх однаково для всіх; нічого від тебе він не отримує.

Якщо хочеш бути паранойєю на 100% — завантаж бібліотеки локально і поклади в
репозиторій (`vendor/`), відріж CDN-теги. Тоді сайт працюватиме навіть офлайн
(`Save As` сторінки + папка з vendor'ами в Downloads — open у будь-якому
браузері без інтернету).

## Локальний запуск без GitHub

`index.html` — самодостатній файл. Подвійний клік (або
**Open with → Chrome/Edge**) запускає його прямо з твого Desktop. Це може
бути корисно, якщо просто потрібно "разово згенерувати" без публікації.

## Якщо щось не так

- **"У реєстрі немає аркуша «Договори»"** — назви аркушів регістрозалежні,
  перевір.
- **Плейсхолдер не замінився**, в готовому документі залишилось `{{XXX}}` —
  мітка в Word-шаблоні розбита на кілька run'ів через нерівне форматування.
  Виділи в Word всю мітку (від `{{` до `}}`), застосуй єдиний шрифт/розмір.
- **`[ERR] рядок N: ...`** — конкретна проблема рядка, текст помилки в
  логу пояснює.
- **Великий зайвий простір у дату/реквізитах** — у шаблоні залишилися
  старі пробіли поряд з мітками. Подивись текст навколо мітки в шаблоні.

## Як змінити

`index.html` — один файл, JS внизу. Перелік міток і логіка лукапа лежать
у функціях `buildContext` та `partyFromRow`. Якщо додаєш нові поля
(наприклад, `{{VYK_IPN}}`) — додай у `buildContext` рядок і поклади відповідне
значення у Word-шаблон.
